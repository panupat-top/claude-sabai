# Chat and Response Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add five chat features to `sabai-band`: a summary line under tool rows (A2), test results as a bar (A3), callout boxes in answers (A4), Thai spinner words (A1) and a guard label under the prompt (A5). Each has its own toggle in a new Chat group in Settings.

**Architecture:** `hooks/chat.ts` holds every parser and line builder as pure functions. `hooks/register.tsx` adds `ui.render` hooks on `ToolUse`, `AssistantMessage`, `Spinner` and `SessionMode`, plus `prompt.compose`, Bash timing in `tool.call`, and a per-turn seed in `turn.start`. The desktop draws each summary line as one SVG made by `hooks/svg.ts`; the terminal draws it as `Text` in theme keys. Task 1 builds the smallest real slice, the Bash line, and checks it on the desktop before anything else depends on SVG or on wrapping.

**Tech Stack:** TypeScript/TSX on Claude Code's function-hooks API (≥ 2.1.287), with the `claude-code/testing` test kit. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-11-chat-design.md`

## Global Constraints

- `register.tsx` is the only module that touches `$`; a helper that takes `$` lives in it (`$` cannot cross an import).
- Pure logic takes plain values and is unit-tested directly (`chat.ts`, like `model.ts` and `agents.ts`).
- A drawn tree must stay under 100,000 characters, and an `Svg` source under 131,072. Svg width and height are 1–4096 px. Ids inside an SVG must be unique and prefixed `sabai-band-`.
- Branch on `e.surface !== 'terminal' && 'Svg' in ui` before drawing `Svg`.
- Transcript `Text` and `Box` colours are theme keys (`success`, `error`, `warning`, `suggestion`, `claude`, `subtle`), never a skin's hex colour. Text inside an SVG uses the OS-following classes, at ≥ 4.5:1 on light and dark.
- Every hook passes through with `next(e)` when its toggle is off or it has nothing to add. Hooks change only what is drawn, never what is stored or sent.
- Values the mod cannot read are hidden, never guessed (a Bash duration it did not measure is left out).
- User-visible text is English, except the spinner words, which are Thai.
- Commit messages: an imperative subject line, then a short bullet list, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Run validate, test and `tsc` before each commit (the pre-commit hook does all three).
- Commands, run from `plugins/sabai-band` unless said otherwise: `claude plugin test .` (all tests, no filter), `tsc -p .`, `claude plugin validate .`.

## Review Focus

1. **A Bash call on a resumed session, with no measured duration:** the line drops the time and never shows `0s`. Test in Task 1.
2. **An Edit whose patch is empty, such as a whitespace-only `replace_all` that matched nothing:** no line is drawn. Test in Task 2.
3. **Output that looks like a test summary but is not, such as `grep "0 fail"` or `echo "5 passed"`:** it must not become a test line unless the full runner pattern matches. Test in Task 4.
4. **A `> [!NOTE]` example inside a fenced code block in an answer:** it stays code and is not drawn as a box. Test in Task 5.
5. **Settings saved by 1.0.0, with no `chat` field:** they load with every chat toggle on and the other choices kept. Test in Task 1.

// What the mod adds to the conversation, as plain values: a summary line under a tool row,
// test results, callouts and the spinner's words. register.tsx draws them per surface.

export type Tone = 'text' | 'muted' | 'ok' | 'bad' | 'warn'
export type Part = { text: string; tone: Tone }
export type LogoKind =
  | 'git' | 'bun' | 'npm' | 'pnpm' | 'nodejs' | 'deno' | 'python' | 'rust'
  | 'golang' | 'docker' | 'typescript' | 'playwright' | 'mocha' | 'jest' | 'bash'
export type Mark = 'pencil' | 'file-added' | 'eye' | 'terminal' | 'stop' | LogoKind
export type Line = { mark: Mark; parts: Part[]; bar?: Tone[] }

// A Bash call this quick that succeeded gets no line: it would only add noise.
const QUIET_MS = 1000

export function seconds(ms: number): string {
  const s = ms / 1000
  if (s < 10) return `${s.toFixed(1)}s`
  if (s < 60) return `${Math.floor(s)}s`
  const m = Math.floor(s / 60)
  return `${m}m ${Math.floor(s % 60)}s`
}

export function bashLine(p: { isErrored: boolean; isInterrupted: boolean; durationMs?: number; mark?: Mark }): Line | undefined {
  const time = p.durationMs === undefined ? undefined : seconds(p.durationMs)
  if (p.isInterrupted) return { mark: 'stop', parts: [{ text: 'interrupted', tone: 'muted' }] }
  const mark = p.mark ?? 'terminal'
  if (p.isErrored) return { mark, parts: [{ text: '✗ failed', tone: 'bad' }, ...(time ? [{ text: ` · ${time}`, tone: 'muted' as const }] : [])] }
  if (p.durationMs === undefined || p.durationMs < QUIET_MS) return undefined
  return { mark, parts: [{ text: '✓', tone: 'ok' }, { text: ` ${time}`, tone: 'muted' }] }
}
```

// The conversation's own ink as [light, dark]: the transcript sits on the person's theme, not on
// a skin's card. Checked at 4.5:1 against white and a dark conversation by the tests.
export const CHAT_INK: Record<Tone, readonly [string, string]> = {
  text: TEXT.t,
  muted: TEXT.m,
  ok: ['#1a7f37', '#3fb950'],
  bad: ['#cf222e', '#ff7b72'],
  warn: ['#9a6700', '#d29922'],
}
const CHAT_CSS =
  Object.entries(CHAT_INK).map(([k, v]) => `.k-${k}{fill:${v[0]}}`).join('') +
  `@media (prefers-color-scheme: dark){${Object.entries(CHAT_INK).map(([k, v]) => `.k-${k}{fill:${v[1]}}`).join('')}}`
const LINE_W = 560
const LINE_H = 20
const MONO_W = 7.2 // a 12px monospace cell

// One summary line: its mark, its words in their tones, then the bar's cells.
export function lineSvg(line: Line): Drawing {
  let x = 22
  const words = line.parts
    .map(p => {
      const t = `<text class="k-${p.tone}" x="${x}" y="14" font-family="${MONO}" font-size="12" xml:space="preserve">${xml(p.text)}</text>`
      x += [...p.text].length * MONO_W
      return t
    })
    .join('')
  const bar = (line.bar ?? []).map((tone, i) => `<rect class="k-${tone}" x="${x + 10 + i * 9}" y="5" width="7" height="10" rx="1.5"/>`).join('')
  const body = `${markSvg(line.mark, 0, 2, 16)}${words}${bar}`
  return {
    source: `<svg xmlns="http://www.w3.org/2000/svg" width="${LINE_W}" height="${LINE_H}" viewBox="0 0 ${LINE_W} ${LINE_H}"><style>${SURFACE_INK}.m{fill:${TEXT.m[0]}}@media (prefers-color-scheme: dark){.m{fill:${TEXT.m[1]}}}${CHAT_CSS}</style>${body}</svg>`,
    width: LINE_W,
    height: LINE_H,
    alt: line.parts.map(p => p.text).join(''),
  }
}

// A line's mark: an Octicon now; Task 3 adds the command logos.
const markSvg = (mark: Mark, x: number, y: number, size: number) => icon(mark as IconKind, x, y, size)
```

// One chat line under (or in place of) a row: an SVG on the desktop, Text in theme keys elsewhere.
function chatLine($: EngineInterface, e: { surface: string }, line: Line) {
  const ui = $.ui.resolve(e as never)
  const { Text } = ui
  if (SVG_IN_CHAT && e.surface !== 'terminal' && 'Svg' in ui) {
    const d = lineSvg(line)
    return <ui.Svg source={d.source} alt={d.alt} />
  }
  return (
    <Text>
      <Text dimColor>{`${MARK_GLYPH[line.mark] ?? '▶'} `}</Text>
      {line.parts.map((p, i) => (
        <Text key={`p${i}`} color={TONE_KEY[p.tone]} dimColor={p.tone === 'muted'}>{p.text}</Text>
      ))}
      {line.bar ? <Text>{' '}</Text> : null}
      {(line.bar ?? []).map((tone, i) => (
        <Text key={`b${i}`} color={TONE_KEY[tone]}>▮</Text>
      ))}
    </Text>
  )
}

const BAR_CELLS = 10

// Cells for a split of two counts, the first in `a`, at least one cell for any non-zero side.
function split(a: number, b: number, toneA: Tone, toneB: Tone): Tone[] {
  const n = a + b
  let cellsA = Math.round((BAR_CELLS * a) / n)
  if (a > 0 && cellsA === 0) cellsA = 1
  if (b > 0 && cellsA === BAR_CELLS) cellsA = BAR_CELLS - 1
  return [...Array<Tone>(cellsA).fill(toneA), ...Array<Tone>(BAR_CELLS - cellsA).fill(toneB)]
}

export function editLine(patch: { lines: string[] }[]): Line | undefined {
  const lines = patch.flatMap(h => h.lines)
  const added = lines.filter(l => l.startsWith('+')).length
  const removed = lines.filter(l => l.startsWith('-')).length
  if (added + removed === 0) return undefined
  const parts: Part[] = [
    { text: `+${added}`, tone: 'ok' },
    { text: ` −${removed}`, tone: 'bad' },
  ]
  if (patch.length > 1) parts.push({ text: ` · ${patch.length} hunks`, tone: 'muted' })
  return { mark: 'pencil', parts, bar: split(added, removed, 'ok', 'bad') }
}

export function writeLine(out: { type: 'create' | 'update'; content: string; structuredPatch: { lines: string[] }[] }): Line | undefined {
  if (out.type === 'update') return editLine(out.structuredPatch)
  const count = out.content.replace(/\n$/, '').split('\n').length
  return { mark: 'file-added', parts: [{ text: 'new file', tone: 'ok' }, { text: ` · ${count} line${count === 1 ? '' : 's'}`, tone: 'muted' }] }
}

export function readLine(out: unknown): Line | undefined {
  const o = out as { type?: string; file?: { startLine?: number; numLines?: number; totalLines?: number } } | undefined
  if (o?.type !== 'text' || !o.file) return undefined
  const { startLine = 1, numLines = 0, totalLines = 0 } = o.file
  if (totalLines === 0) return undefined
  if (startLine <= 1 && numLines >= totalLines) return { mark: 'eye', parts: [{ text: `all ${totalLines} lines`, tone: 'text' }] }
  return { mark: 'eye', parts: [{ text: `lines ${startLine}–${startLine + numLines - 1}`, tone: 'text' }, { text: ` of ${totalLines}`, tone: 'muted' }] }
}

```ts
const RUNNERS = new Set(['sudo', 'time', 'npx', 'bunx', 'exec', 'nice', 'env'])
const LOGO_OF: Record<string, LogoKind> = {
  git: 'git', bun: 'bun', npm: 'npm', pnpm: 'pnpm', node: 'nodejs', deno: 'deno',
  python: 'python', python3: 'python', pip: 'python', pip3: 'python', pytest: 'python', uv: 'python',
  cargo: 'rust', rustc: 'rust', go: 'golang', docker: 'docker', tsc: 'typescript',
  playwright: 'playwright', mocha: 'mocha', jest: 'jest',
}

export function commandOf(command: string): string {
  const last = command.split(/&&|\|\||;/).map(s => s.trim()).filter(s => s && !/^cd\s/.test(s)).at(0) ?? ''
  const words = last.match(/(?:[^\s"']+|"[^"]*"|'[^']*')+/g) ?? []
  for (let i = 0; i < words.length; i++) {
    const w = words[i]!
    if (/^[A-Za-z_][A-Za-z0-9_]*=/.test(w) || RUNNERS.has(w)) continue
    if (w === 'pnpm' && (words[i + 1] === 'dlx' || words[i + 1] === 'exec')) { i++; continue }
    return w.split('/').pop()!
  }
  return ''
}

export function logoOf(command: string): LogoKind {
  return LOGO_OF[commandOf(command)] ?? 'bash'
}
```

Rule: `pnpm dlx tool` and `pnpm exec tool` name the tool, while `pnpm i` names pnpm. The code above skips `pnpm` only when `dlx` or `exec` follows it, so `pnpm i` resolves to `pnpm`.

```ts
export type TestRunner = 'bun' | 'jest' | 'vitest' | 'pytest' | 'cargo' | 'go'
type Counts = { passed: number; failed: number; skipped: number }

const lastMatch = (text: string, re: RegExp) => [...text.matchAll(re)].at(-1)
const count = (words: string, word: RegExp) => Number(words.match(new RegExp(`(\\d+) ${word.source}`))?.[1] ?? 0)

const PARSERS: [TestRunner, (t: string) => Counts | undefined][] = [
  ['bun', t => {
    if (!/^Ran \d+ tests? across/m.test(t)) return undefined
    const n = (w: string) => Number(lastMatch(t, new RegExp(`^\\s*(\\d+) ${w}$`, 'gm'))?.[1] ?? 0)
    return { passed: n('pass'), failed: n('fail'), skipped: n('skip') }
  }],
  ['vitest', t => {
    const m = lastMatch(t, /^\s*Tests\s{2,}(.+?)\s\((\d+)\)\s*$/gm)
    return m ? { passed: count(m[1]!, /passed/), failed: count(m[1]!, /failed/), skipped: count(m[1]!, /skipped/) } : undefined
  }],
  ['jest', t => {
    const m = lastMatch(t, /^Tests:\s+(.+?),?\s+(\d+) total$/gm)
    return m ? { passed: count(m[1]!, /passed/), failed: count(m[1]!, /failed/), skipped: count(m[1]!, /skipped/) } : undefined
  }],
  ['pytest', t => {
    const m = lastMatch(t, /^=+ (.+?) in [\d.]+s(?: \([^)]*\))? =+$/gm)
    return m ? { passed: count(m[1]!, /passed/), failed: count(m[1]!, /failed/) + count(m[1]!, /errors?/), skipped: count(m[1]!, /skipped/) } : undefined
  }],
  ['cargo', t => {
    const all = [...t.matchAll(/^test result: (?:ok|FAILED)\. (\d+) passed; (\d+) failed; (\d+) ignored/gm)]
    if (!all.length) return undefined
    return all.reduce((a, m) => ({ passed: a.passed + Number(m[1]), failed: a.failed + Number(m[2]), skipped: a.skipped + Number(m[3]) }), { passed: 0, failed: 0, skipped: 0 })
  }],
  ['go', t => {
    const pass = (t.match(/^\s*--- PASS:/gm) ?? []).length
    const fail = (t.match(/^\s*--- FAIL:/gm) ?? []).length
    const skip = (t.match(/^\s*--- SKIP:/gm) ?? []).length
    if (pass + fail + skip) return { passed: pass, failed: fail, skipped: skip }
    const ok = (t.match(/^ok\s+\S+\s+[\d.]+s/gm) ?? []).length
    const bad = (t.match(/^FAIL\s+\S+\s+[\d.]+s/gm) ?? []).length
    return ok + bad ? { passed: ok, failed: bad, skipped: 0 } : undefined
  }],
]

export function testResult(text: string): ({ runner: TestRunner } & Counts) | undefined {
  for (const [runner, parse] of PARSERS) {
    const c = parse(text)
    if (c && c.passed + c.failed + c.skipped > 0) return { runner, ...c }
  }
  return undefined
}

const RUNNER_LOGO: Partial<Record<TestRunner, LogoKind>> = { bun: 'bun', jest: 'jest', pytest: 'python', cargo: 'rust', go: 'golang' }

export function testLine(r: { runner: TestRunner } & Counts, durationMs?: number): Line {
  const mark = RUNNER_LOGO[r.runner] ?? 'terminal'
  const time: Part[] = durationMs === undefined ? [] : [{ text: ` · ${seconds(durationMs)}`, tone: 'muted' }]
  if (r.failed === 0) return { mark, parts: [{ text: `✓ all ${r.passed} passed 🎉`, tone: 'ok' }, ...time], bar: Array<Tone>(BAR_CELLS).fill('ok') }
  const skipped: Part[] = r.skipped ? [{ text: ` · ${r.skipped} skipped`, tone: 'muted' }] : []
  return {
    mark,
    parts: [{ text: `✗ ${r.failed} of ${r.passed + r.failed} failed`, tone: 'bad' }, ...skipped, ...time],
    bar: split(r.passed, r.failed, 'ok', 'bad'),
  }
}
```

```ts
export type CalloutKind = 'note' | 'tip' | 'important' | 'warning' | 'caution'
export type Segment = { kind: 'md'; text: string } | { kind: 'callout'; type: CalloutKind; body: string }

const MARKER = /^>\s*\[!(note|tip|important|warning|caution)\]\s*(.*)$/i

export function splitCallouts(md: string): Segment[] {
  const out: Segment[] = []
  let text: string[] = []
  let fence: string | undefined
  const flush = () => {
    if (text.length) out.push({ kind: 'md', text: text.join('\n') })
    text = []
  }
  const lines = md.split('\n')
  for (let i = 0; i < lines.length; i++) {
    const line = lines[i]!
    const f = line.match(/^\s*(```+|~~~+)/)?.[1]
    if (f) fence = fence === undefined ? f[0] : f[0] === fence ? undefined : fence
    const m = fence === undefined && !f ? line.match(MARKER) : null
    if (!m) {
      text.push(line)
      continue
    }
    flush()
    const body = m[2] ? [m[2]] : []
    while (i + 1 < lines.length && /^>/.test(lines[i + 1]!) && !MARKER.test(lines[i + 1]!)) body.push(lines[++i]!.replace(/^>\s?/, ''))
    out.push({ kind: 'callout', type: m[1]!.toLowerCase() as CalloutKind, body: body.join('\n') })
    // The blank line that closes a callout belongs to it, not to the next text.
    if (lines[i + 1] === '') i++
  }
  flush()
  return out
}

export type SpinnerMode = 'requesting' | 'responding' | 'thinking' | 'tool-input' | 'tool-use'

// Plain Thai, at a glance; the engine adds its own ellipsis after the word.
export const SPINNER_WORDS: Record<SpinnerMode, readonly string[]> = {
  thinking: ['กำลังคิด', 'ขอคิดแป๊บนึงนะ', 'กำลังเรียบเรียงความคิด', 'กำลังหาทางที่ดีที่สุด'],
  requesting: ['กำลังส่งคำขอ', 'รอคำตอบสักครู่'],
  'tool-input': ['กำลังเตรียมคำสั่ง'],
  'tool-use': ['กำลังลงมือทำ', 'กำลังจัดการให้', 'กำลังตรวจดูให้'],
  responding: ['กำลังเขียนคำตอบ', 'กำลังสรุปให้', 'ใกล้เสร็จแล้ว'],
}

export function seedOf(id: string): number {
  let h = 0
  for (const c of id) h = (h * 31 + c.codePointAt(0)!) >>> 0
  return h
}

export function spinnerWord(mode: SpinnerMode, seed: number): string {
  const words = SPINNER_WORDS[mode]
  return words[seed % words.length]!
}

// The desktop says `Working` while its row names no step; a word naming a step is kept.
export const isGenericWord = (word: string) => word.trim() === '' || word.trim() === 'Working'
```
