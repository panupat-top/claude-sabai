# sabai 2.5.0 — race lanes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lanes in the race box show how far each member has come (runner paced by its calls, footprints trailing it), and lanes not at work (Main waiting, finished agents) fold to one 18 px line.

**Architecture:** The race log gains a per-member call `count` (pure reducers in `model.ts`); `raceOf` (`agents.ts`) passes it on each lane and splits Main's idle states into `waiting` (not working) and `thinking` (working, no call in flight); `racePart` (`svg.ts`) places the runner at its progress or `paceOf(count)`, draws the tiles behind it, scrolls a dashed ground, and draws `waiting`/`finished` lanes slim.

**Tech Stack:** TypeScript, Claude Code function-hooks API (≥ 2.1.287), tests via `claude-code/testing`, SVG strings.

**Spec:** `docs/superpowers/specs/2026-10-12-sabai-2.5-race-lanes-design.md`
