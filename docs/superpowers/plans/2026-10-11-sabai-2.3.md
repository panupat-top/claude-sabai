# sabai 2.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** sabai 2.3.0:
- Clawd says what his mood means and does tricks;
- the usage limits fill the comfortable band in one of four styles, with no forecast;
- the race box shows who does what for how long, merging agents of one type;
- the settings pane is regrouped.

**Architecture:**
- **Pure logic** stays in `model.ts` (`moodLine`, `trickOf`, `resetClock`, `raced`) and `agents.ts` (`raceOf`).
- **Drawing** stays in `svg.ts` (the hero panel, `usagePart` with four styles, `racePart`) and `sprites.ts` (trick modes).
- **`register.tsx`** reads state, computes the facts, passes them in `BandOpts`, and renders the settings pane.
- **New prefs:** `prefs.extras` and `prefs.usageStyle`.

**Tech Stack:** TypeScript, Claude Code function-hooks API (`claude-code`), `claude-code/testing`, SVG strings.

**Spec:** `docs/superpowers/specs/2026-10-11-sabai-2.3-design.md`

## Global Constraints

**Branch and checks:**
- Work on a new branch `sabai-2.3` cut from `sabai-2.2` (2.2 is not merged yet).
- Before each commit, run from the repo root (the pre-commit hook does the same):
  - `claude plugin validate plugins/sabai`
  - `claude plugin test plugins/sabai` (no per-test filter: it runs every test)
  - `tsc -p plugins/sabai`
- No new dependencies.

**Project rules:**
- Values the mod cannot read are hidden, never faked. No credentials, no external files, no network.
- User-visible text is English. The Thai spinner words are the only exception.
- Text colours are ≥ 4.5:1 on their own background. Words on a card (`.p`) take the skin's ink classes (`t`, `m`, `c-*`). Words on the bare surface take `st`, `sm`, `s-*`.

**Desktop limits:**
- A render tree must stay under 100,000 serialized characters.
- An `Svg` source must be ≤ 131,072 characters, 1–4096 px each way.
- An SVG drawn as an image fails whole on invalid XML, e.g. two `class` attributes on one element.
- Animations loop in ≤ 1 s or run once, start from a visible frame, and use transforms or opacity only.

**Engine rules:**
- Helpers that take `$` are top-level functions in `register.tsx`.
- An event registered twice without a matcher is refused at load, so extend the existing hook.
- Work started from a button press must be queued through `$.clock.after`.

**Commits:**
- An imperative subject, then a short bullet list.
- End with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A mood whose fact is missing** (sad with no test count, sleeping with `lastTurnAt` 0) shows its headline alone: never `undefined failed` or `idle NaNm`. Pinned in Task 2.
2. **Band heights:**
   - Clawd hidden, no race, usage only: the usage gets its 50 px floor, and no negative or zero card height.
   - Usage row off: no usage part.
   - Pinned in Task 5.
3. **Reset clock times:**
   - a reset past midnight shows the weekday;
   - context has no reset, so it shows `left`;
   - a limit without `resetsAt` shows no second detail.
   - Pinned in Task 5.
4. **Merging:**
   - four running agents of four different types: nothing merges, `+1` remains;
   - merged lanes with ended agents present: ended lanes come after the running ones.
   - Pinned in Task 4.
5. **Look-right** when a race is computed but not drawn (band under 760 px): Clawd does not look right. Pinned in Task 3.

`model.ts`, after `moodOf`:

```ts
// The facts Clawd's second line is made of; any may be missing.
export type MoodFacts = { caught?: number; passed?: number; failed?: number; contextPercent?: number; idleMs?: number }
const known = (n: number | undefined): n is number => n !== undefined && Number.isFinite(n)
// Why Clawd feels as he does, in a few words, or nothing when the fact behind it is missing.
// Working says nothing here: the panel shows the turn's time.
export function moodLine(mood: Mood, f: MoodFacts): string | undefined {
  switch (mood) {
    case 'idle': return 'your turn'
    case 'startled': return known(f.caught) && f.caught > 0 ? `guard stopped ${f.caught}` : undefined
    case 'sad': return known(f.failed) && f.failed > 0 ? `${f.failed} failed` : undefined
    case 'celebrating': return known(f.passed) ? `${f.passed} passed` : undefined
    case 'sweating': return known(f.contextPercent) ? `${Math.round(f.contextPercent)}% · compact?` : undefined
    case 'sleeping': {
      if (!known(f.idleMs)) return undefined
      const m = Math.floor(f.idleMs / 60_000)
      return m >= 60 ? `idle ${Math.floor(m / 60)}h` : `idle ${m}m`
    }
    default: return undefined
  }
}
```

export type Trick = 'wave' | 'yawn' | 'look-right' | 'look-up'
export const WAVE_MS = 3000
export const YAWN_AFTER_MS = 2 * 60_000
// A trick for Clawd when his mood has no look of its own (idle or working): a wave as a turn

export function trickOf(s: { mood: Mood; now: number; lastTurnAt: number; isWorking: boolean; raceShown: boolean; limitHigh: boolean }): Trick | undefined {

const DAYS = ['Sun', 'Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat']
// A limit's reset as a local clock time: `resets 14:30` today, `resets Thu 09:00` past it.
export function resetClock(resetsInMs: number | undefined, now: number): string | undefined {
  if (resetsInMs === undefined || !Number.isFinite(resetsInMs)) return undefined
  const at = new Date(now + resetsInMs)
  const hm = `${String(at.getHours()).padStart(2, '0')}:${String(at.getMinutes()).padStart(2, '0')}`
  return at.toDateString() === new Date(now).toDateString() ? `resets ${hm}` : `resets ${DAYS[at.getDay()]} ${hm}`
}
