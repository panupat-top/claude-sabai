# sabai 2.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship sabai 2.2.0:
- a live turn strip;
- usage forecasts on the 5H and 7D cards;
- band choices: chips, cards, thresholds, Clawd;
- a light/dark skin pair;
- compact density;
- Clawd's time-of-day and holiday accessories;
- the six 2.1 minors;
- desktop checks.

**Architecture:**
- Prefs grow `show`, `warnAt`/`alertAt`, `darkSkin`, `density` and `rows.live`.
- `meters()` and `chips()` filter by `show`, and give each meter its warning `level` and `forecast`.
- `bandSvg` takes an options object carrying mood, skin choice, density, live strip and accessory.
- A skin pair is a Look whose colours are CSS custom properties, switched by `@media (prefers-color-scheme: dark)`. Single skins keep today's hex Look.
- New pure functions (`forecastOf`, `accessoryOf`, `isReadOnly`) live in `model.ts`/`chat.ts`.

**Tech Stack:** Claude Code function-hooks mod (TypeScript/TSX), `claude-code/testing`, SVG strings.

**Spec:** `docs/superpowers/specs/2026-10-11-sabai-2.2-design.md`

## Global Constraints

- **Code layout:** mod folder `plugins/sabai`. Only `hooks/register.tsx` touches `$`. A helper taking `$` is a top-level function declaration in `register.tsx`. The engine refuses any other form.
- **Hook registration:** an event registered twice without a matcher is refused at load, so extend the existing hook instead (`turn.start`, `turn.complete`, the bare `tool.call`).
- **Contract types:** `plugins/sabai/types/index.d.ts` is self-contained, with no `import`.
- **Copy:** user-visible text is in English. The Thai spinner words are the one exception.
- **Contrast:** every text colour is ≥ 4.5:1 on its card (`tests/themes.test.ts`).
- **Size limits:** a render tree stays under 100,000 characters serialized. An Svg is 1–4096 px wide and tall, with a source of at most 131,072 characters.
- **Animation:** loops are ≤ 1 s or run once, start from a visible frame, use transforms or opacity, and stop under reduced motion.
- **Transcript colours** are theme keys. Skins apply to `svg.ts` drawings only.
- **Desktop Buttons** draw from `label` alone.
- **Release:** bump `version` in both `plugins/sabai/.claude-plugin/plugin.json` and `.claude-plugin/marketplace.json`.
- **Commits:** an imperative subject and a short bullet list, ending with the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Before every commit**, run from the repo root:
  - `claude plugin validate plugins/sabai`
  - `tsc -p plugins/sabai`
  - `claude plugin test plugins/sabai > /tmp/sabai.log 2>&1; grep -E "^\(fail\)| pass$| fail$" /tmp/sabai.log`

  The test runner has no per-test filter.
- **Test hooks:** a test's own `on(...)` registered before `engine(on)` sits closer to the plugin than `engine`'s catch-all. Register a specific `tool.call` answer before `engine(on)`.

## Review Focus

```ts
// A command that only reads: each part of a chain is a reader, and nothing is written to a file.
const READERS = /^(?:cat|head|tail|less|more|grep|rg|ls|find|wc|tree|pwd|which|file|stat|du|df|git\s+(?:status|log|diff|show|branch|blame|rev-parse|remote))\b/
export function isReadOnly(command: string): boolean {
  if (/[^>]>[^&]|>>|\btee\b|-i\b/.test(command)) return false
  return bare(command).split(/&&|\|\||;|\|/).map(p => p.trim()).filter(Boolean).every(p => READERS.test(p))
}
```

```ts
// One line per card: its mark (context only), label, bar, percent, and the reset countdown when
// there is room.
function compactCard(look: Look, m: Meter, x: number, y: number, w: number, style: BarStyle): string {
  const labelX = m.kind === 'context' ? x + PAD + 26 : x + PAD
  const label = m.kind === 'context' ? 'CTX' : m.label.split(' ')[0]!.toUpperCase()
  const after = m.resetsInMs === undefined ? '' : ` ↻${countdown(m.resetsInMs).replace(' ', '')}`
  const tail = `${m.percent}%${after}`
  const barX = labelX + monoWidth(label, 10) + 8
  const barW = Math.max(30, x + w - PAD - monoWidth(tail, 11) - 8 - barX)
  return (
    `<rect class="p" x="${x}" y="${y}" width="${w}" height="22" rx="6"/>` +
    (m.kind === 'context' ? sprite('context', x + PAD + 1, y + 11 - spriteSize('context').height / 2) : '') +
```

`model.ts`:

```ts
export type Point = { at: number; percent: number }
const RECENT_MS = 30 * 60_000
// Where a limit is heading by its reset at the recent rate (a least-squares slope over the last
// half hour), or nothing without two readings five minutes apart and a rising rate.
export function forecastOf(points: Point[], resetsInMs: number | undefined, now: number): number | undefined {
  if (resetsInMs === undefined) return undefined
  const recent = points.filter(p => now - p.at <= RECENT_MS)
  if (recent.length < 2 || recent.at(-1)!.at - recent[0]!.at < 5 * 60_000) return undefined
  const mx = recent.reduce((s, p) => s + p.at, 0) / recent.length
  const my = recent.reduce((s, p) => s + p.percent, 0) / recent.length
  const den = recent.reduce((s, p) => s + (p.at - mx) ** 2, 0)
  const rate = den ? recent.reduce((s, p) => s + (p.at - mx) * (p.percent - my), 0) / den : 0
  if (rate <= 0) return undefined
  const last = recent.at(-1)!.percent
  const ahead = Math.min(100, Math.round(last + rate * resetsInMs))
  return ahead >= last + 1 ? ahead : undefined
}
```

`model.ts`:

```ts
export type Accessory = 'newyear' | 'xmas' | 'halloween' | 'songkran' | 'coffee' | 'nightcap'
// What Clawd wears for the local date and hour: a holiday first, else the time of day.
export function accessoryOf(d: Date): Accessory | undefined {
  const m = d.getMonth() + 1
  const day = d.getDate()
  const h = d.getHours()
  if ((m === 12 && day === 31) || (m === 1 && day === 1)) return 'newyear'
  if (m === 12 && (day === 24 || day === 25)) return 'xmas'
  if (m === 10 && day === 31) return 'halloween'
  if (m === 4 && day >= 13 && day <= 15) return 'songkran'
  if (h >= 6 && h < 11) return 'coffee'
  if (h >= 22 || h < 5) return 'nightcap'
  return undefined
}
```
