# sabai 2.2.0 Band Layout and Race Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Draw the comfortable band in three panels (Clawd, info + usage rows, a race box) and add the game-style race. In the race, Main and each subagent run their own lane, with a tool in hand, a glow underfoot, call tiles, coins, trips and finish flags.

**Architecture:**
- A `race` atom records each member's calls, the call in flight and its last fail/score times. The existing `tool.call`, `turn.start` and `agent.spawn` hooks write it.
- `raceOf()` in `model.ts` turns that into lanes and a header, as a pure function.
- `svg.ts` gains `heroBand` (the prototype already in the working tree), `usageRows` and `racePart`.
- `bandSvg` chooses the layout from `opts.hero` and the width: ≥ 760 three panels, 480–759 two panels, < 480 stacked. `register.tsx` passes `hero: true` in comfortable density.

**Tech Stack:** Claude Code function-hooks mod (TypeScript/TSX), `claude-code/testing`, SVG strings.

**Spec:** `docs/superpowers/specs/2026-10-11-sabai-2.2-band-layout-design.md` (extends `2026-10-11-sabai-2.2-design.md`)

**Where this sits:**
- The branch is `sabai-2.2`, with Tasks 1–9 of `docs/superpowers/plans/2026-10-11-sabai-2.2.md` done.
- Task 10 of that plan (the release docs) is carried here as Task 6.
- The working tree holds an uncommitted prototype in `plugins/sabai/hooks/svg.ts`: `heroBand`, `usageRows`, `HERO_*` constants, `MOOD_WORDS` and the `hero` option. Task 1 puts it under tests and commits it.

## Global Constraints

- **Code layout:** mod folder `plugins/sabai`. Only `hooks/register.tsx` touches `$`, through top-level function declarations.
- **Hook registration:** an event registered twice without a matcher is refused, so extend the existing hooks.
- **Contract types:** `plugins/sabai/types/index.d.ts` is self-contained (no `import`).
- **Copy:** user-visible text is English.
- **Contrast:** text colours are ≥ 4.5:1 on their card.
- **Size limits:** a render tree stays < 100,000 characters. An Svg is 1–4096 px and ≤ 131,072 characters. Clip-path ids are unique.
- **Animation:** ≤ 1 s loops or run once, a visible first frame, transforms/opacity only, still under `prefers-reduced-motion`.
- **Desktop image:** an SVG on the desktop is an image, so no hover or interaction.
- **Commits:** an imperative subject and bullets, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Before each commit:**
  - `claude plugin validate plugins/sabai`
  - `tsc -p plugins/sabai`
  - `claude plugin test plugins/sabai > /tmp/sabai.log 2>&1; grep -E "^\(fail\)| pass$| fail$" /tmp/sabai.log`
- **Test hooks:** a specific test hook registered before `engine(on)` sits closer to the plugin. The test kit refuses a second registration of an event `engine()` already answers.

## Review Focus

1. **A subagent that never reports steps and has no task list.** Its runner must hold the lane's middle while the ground scrolls, not sit at 0 or vanish. Pinned in Task 2 (`progress` undefined).
2. **Main's turn ends while a subagent still runs.** The race must stay with the agent's lane and Main `waiting`, and leave only when every agent ends and the linger passes. Pinned in Task 2.
3. **Many quick calls (60+) in one lane.** Only the last 16 tiles are kept and drawn, and the tree stays small. Pinned in Task 3 (cap) and Task 4 (tree limit).
4. **The band crossing 760 or 480 px as the window resizes.** Each tier draws, with no missing info and no rows drawn twice: the live strip and crew rows are present only below 760. Pinned in Task 4.
5. **Clawd hidden with the race on.** The Clawd panel is gone, the middle starts at the left edge, and the race still shows. Pinned in Task 4.

```ts
export const EMPTY_RACE: RaceLog = { calls: {}, doing: {}, fellAt: {}, scoredAt: {}, combo: 0, coins: 0, mainFails: 0, total: 0 }
export const TRIP_MS = 4000
export const SCORE_MS = 3000
export const RACE_TILES = 16
export const RACE_LANES = 3

// One finished call of a member folded into the race: its tile, the shared combo and coins, and
// Main's lost hearts.
export function raced(log: RaceLog, member: string, call: { kind: CallKind; ok: boolean }, at: number): RaceLog {
  const tiles = [...(log.calls[member] ?? []), call].slice(-RACE_TILES)
  return {
    ...log,
    calls: { ...log.calls, [member]: tiles },
    combo: call.ok ? log.combo + 1 : 0,
    coins: log.coins + (call.kind === 'test' && call.ok ? 1 : 0),
    mainFails: log.mainFails + (member === 'main' && !call.ok ? 1 : 0),
    fellAt: call.ok ? log.fellAt : { ...log.fellAt, [member]: at },
    scoredAt: call.kind === 'test' && call.ok ? { ...log.scoredAt, [member]: at } : log.scoredAt,
    total: log.total + 1,
  }
}

const AGENT_NAME = (type: string) => (type === 'general-purpose' ? 'General' : type.includes(':') ? type.split(':').pop()! : type)

// The race as drawn: Main and the newest agents, each in its state, with the header's counts;
// nothing while neither the main turn nor any agent is at work.
export function raceOf(log: RaceLog, agents: AgentRun[], tasks: Progress | undefined, now: number, mainWorking: boolean, turnStartedAt: number, mainStep?: string): Race | undefined {
  const running = agents.filter(a => a.status === 'running')
  if (!mainWorking && running.length === 0) return undefined
  const timed = (id: string): LaneState | undefined =>
    now - (log.fellAt[id] ?? -Infinity) < TRIP_MS ? 'tripped' : now - (log.scoredAt[id] ?? -Infinity) < SCORE_MS ? 'scored' : undefined
  const main: Lane = {
    id: 'main',
    who: 'Main',
    note: mainStep ?? (mainWorking ? 'Working' : 'Waiting'),
    ...(tasks ? { progress: tasks.done / tasks.total } : {}),
    calls: log.calls.main ?? [],
    ...(log.doing.main ? { doing: log.doing.main } : {}),
    state: timed('main') ?? (mainWorking ? (log.doing.main ? 'running' : 'waiting') : 'waiting'),
  }
  const shown = [...running, ...agents.filter(a => a.status !== 'running').sort((a, b) => (b.endedAt ?? 0) - (a.endedAt ?? 0))]
  const lanes = shown.slice(0, RACE_LANES).map((a): Lane => {
    const id = a.agentId ?? a.id
    const p = progressOf(a)
    const state: LaneState = a.status === 'failed' ? 'out' : a.status === 'done' ? 'finished' : (timed(id) ?? 'running')
    return {
      id,
      who: AGENT_NAME(a.type),
      type: a.type,
      note: state === 'out' ? 'Failed' : state === 'finished' ? 'Done' : p ? `${p.done}/${p.total}` : a.description,
      ...(state === 'finished' ? { progress: 1 } : p ? { progress: p.done / p.total } : {}),
      calls: log.calls[id] ?? [],
      ...(log.doing[id] ? { doing: log.doing[id] } : {}),
      state,
    }
  })
  const since = mainWorking ? turnStartedAt : Math.min(...running.map(a => a.startedAt))
  return { lv: Math.floor(log.total / 5) + 1, coins: log.coins, hearts: Math.max(0, 3 - log.mainFails), combo: log.combo, elapsedMs: Math.max(0, now - since), more: Math.max(0, shown.length - RACE_LANES), lanes: [main, ...lanes] }
}
```

```ts
// A member's call in flight and, once it finished, its tile in the race.
async function racing($: EngineInterface, agentId: string | undefined, kind: CallKind | undefined, called?: { deny?: string; isError?: boolean }, ok?: boolean) {
  const member = agentId ?? 'main'
  if (!kind) return
  if (!called) {
    await update($, race, r => ({ ...r, doing: { ...r.doing, [member]: kind } }))
    return
  }
  const at = await $.clock.now()
  await update($, race, r => {
    const { [member]: _, ...doing } = r.doing
    return called.deny !== undefined ? { ...r, doing } : raced({ ...r, doing }, member, { kind, ok: ok ?? !called.isError }, at)
  })
}
```
