# sabai 2.4.0 — the info row Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the info row's five boxed chips with one minimal line:
- left: project name, a branch tag and the sync counts;
- right: guard, Node and git user in muted ink, dropping from the right as room runs out.

**Architecture:**
- `chips()` keeps its shape for the terminal and the alt. The branch chip gains structured fields (`branch`, `ahead`, `behind`, `changes`).
- `icons.ts`'s `icon()` gains an optional class.
- A new `infoPart` in `svg.ts` replaces `chipsPart` in the hero and the stacked band, drawing from the chips by their icon.

**Tech Stack:** TypeScript, Claude Code function-hooks API, `claude-code/testing`, SVG strings.

**Spec:** `docs/superpowers/specs/2026-10-11-sabai-2.4-info-design.md`

## Global Constraints

**Branch and checks:**
- Branch `sabai-2.4` (cut from `main` at 2.3.0).
- Before each commit, run from the repo root:
  - `claude plugin validate plugins/sabai`
  - `claude plugin test plugins/sabai`
  - `tsc -p plugins/sabai`
- No new dependencies.

**Project rules:**
- Values the mod cannot read are hidden, never faked.
- User-visible text is English.
- Text colours are ≥ 4.5:1 on their own background. The info row sits on the bare surface, so its words take the surface classes `st`, `sm` and `s-*`.

**Desktop limits:**
- A render tree must stay under 100,000 serialized characters.
- An Svg source must be ≤ 131,072 characters.
- The SVG must be valid XML: no element with two `class` attributes.

**Commits:** an imperative subject, a short bullet list, then `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

`icons.ts`:

```ts
// The mark drawn `size` pixels square with its top-left at (x, y); `cls` paints it with a class
// (the surface's muted ink, say) instead of its own colour.
export function icon(kind: IconKind, x: number, y: number, size: number, cls?: string): string {
  const { box, fill, d } = ICONS[kind]
  const paint = cls ? `class="${cls}"` : fill.startsWith('.') ? `class="${fill.slice(1)}"` : `fill="${fill}"`
  return `<path ${paint} transform="translate(${x},${y}) scale(${size / box})" d="${d}"/>`
}
```

- [ ] **Step 3: Implement infoPart**

In `svg.ts`, add the code below beside `chipsPart`:

```ts
const INFO_H = 22
// The info row: the project, its branch as a tinted tag with the sync counts, then at the right
// the guard, Node and the git user as small marks in the muted ink. Room runs out from the right:
// the user goes first, then the guard; Node stays; then the branch and folder names are cut.
function infoPart(info: { left: readonly Chip[]; right: readonly Chip[] }, W: number, y: number, look: Look, clawd?: { look: Look; mood: Mood; accessory?: Accessory; trick?: Trick }): Part {
  const all = [...info.left, ...info.right]
  const by = (k: IconKind) => all.find(c => c.icon === k)
  const folder = by('folder'), branch = by('branch'), user = by('git'), node = by('node'), guard = by('shield')
  const mid = y + INFO_H / 2
  const lead = clawd ? clawdAt(clawd.look, 0, y + (INFO_H - spriteSize('tasks').height) / 2, clawd.mood, clawd.accessory, clawd.trick) : ''
  const x0 = clawd ? spriteSize('tasks').width + GAP : 0
  // The right side, in its order, each with how long it stays when room is short.
  const items = [
    guard && { k: 'shield' as const, v: guard.value.replace(' · ', ' '), keep: 2 },
    node && { k: 'node' as const, v: node.value.match(/^v?\d+/)?.[0] ?? node.value, keep: 3 },
    user && { k: 'git' as const, v: user.value, keep: 1 },
  ].filter(Boolean) as { k: IconKind; v: string; keep: number }[]
  const itemW = (i: { v: string }) => 12 + 5 + monoWidth(i.v, 10.5)
  const rightW = (list: typeof items) => list.reduce((n, i) => n + itemW(i), 0) + 16 * Math.max(0, list.length - 1)
  const counts = branch && branch.branch !== undefined
    ? ([[branch.ahead, '↑', 's-ok'], [branch.behind, '↓', 's-context'], [branch.changes, '±', 's-warn']] as const).filter(([n]) => n !== undefined && n > 0).map(([n, mark, cls]) => ({ s: `${mark}${n}`, cls }))
    : []
  const countsW = counts.reduce((n, c) => n + monoWidth(c.s, 10.5) + 7, 0)
  const name = branch ? (branch.branch ?? branch.value) : ''
  const tagW = (s: string) => 8 + 12 + 5 + monoWidth(s, 11) + 9
  const folderW = (s: string) => 19 + textWidth(s, 14.5) + 12
  const leftW = (f: string, b: string) => x0 + (folder ? folderW(f) : 0) + (branch ? tagW(b) + 10 : 0) + countsW
  let shown = items
  while (shown.length && leftW(folder?.value ?? '', name) + 12 > W - rightW(shown)) {
    const least = Math.min(...shown.map(i => i.keep))
    shown = shown.filter(i => i.keep !== least)
  }
  // Still too wide with nothing at the right: cut the branch (to six characters), then the folder.
  let b = name
  let f = folder?.value ?? ''
  if (!shown.length && leftW(f, b) > W) b = fitMono(b, 11, Math.max(monoWidth(b.slice(0, 6) + '…', 11), W - leftW(f, '') - tagW('') - 10))
  if (!shown.length && leftW(f, b) > W) f = fit(f, 14.5, Math.max(20, W - leftW('', b) - 31))
  let x = x0
  let body = lead
  if (folder) {
    body += icon('folder', x, mid - 6.5, 13, 'sm') + `<text class="st" x="${x + 19}" y="${mid + 5}" font-family="${SANS}" font-size="14.5" font-weight="700">${xml(f)}</text>`
    x += folderW(f)
  }
  if (branch) {
    const tw = tagW(b)
    body += `<rect x="${x}" y="${mid - 10}" width="${tw}" height="20" rx="10" fill="${look.bar('session')}" opacity=".13"/>` +
      icon('branch', x + 8, mid - 6, 12, 's-session') +
      `<text class="s-session" x="${x + 25}" y="${mid + 4}" font-family="${MONO}" font-size="11" font-weight="600">${xml(b)}</text>`
    x += tw + 10
    for (const c of counts) {
      body += `<text class="${c.cls}" x="${x}" y="${mid + 4}" font-family="${MONO}" font-size="10.5" font-weight="600">${c.s}</text>`
      x += monoWidth(c.s, 10.5) + 7
    }
  }
  let rx = W - rightW(shown)
  for (const i of shown) {
    body += icon(i.k, rx, mid - 6, 12, 'sm') + `<text class="sm" x="${rx + 17}" y="${mid + 4}" font-family="${MONO}" font-size="10.5">${xml(i.v)}</text>`
    rx += itemW(i) + 16
  }
  const drawn = all.filter(c => (c.icon === 'folder' && folder) || (c.icon === 'branch' && branch) || shown.some(i => i.k === c.icon))
  const alt = drawn.map(c => `${c.label} ${c.value}`).join(', ') + (clawd ? moodSaid(clawd.mood) : '')
  return { body: `<g>${body}</g><!--info-->`, height: INFO_H, alt: alt.replace(/^; /, '') }
}
```
