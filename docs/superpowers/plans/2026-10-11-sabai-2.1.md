# sabai 2.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship sabai 2.1.0. It has five parts:
- a guard that fails closed;
- a turn receipt under each working turn's answer;
- per-rule guard actions (Block / Ask / Off) with a new `discard` rule and a count;
- Clawd's moods;
- an up-to-date description.

**Architecture:**
- A `turnLog` atom, reset by each main `turn.start`, is written by `tool.call` hooks on Edit/Write/Bash and by the guard.
- Two pure functions read it, `receiptText` (chat.ts) and `moodOf` (model.ts). `turn.complete` shows the receipt; the band's Clawd draws the mood.
- Guard Block stays on `tool.call`, now with a `.catch` that refuses; guard Ask is a new `classic.PreToolUse` hook.

**Tech Stack:** Claude Code function-hooks mod (TypeScript/TSX, engine ≥ 2.1.287), `claude-code/testing` test kit, SVG strings for the desktop.

**Spec:** `docs/superpowers/specs/2026-10-11-sabai-2.1-design.md`

## Global Constraints

- Mod folder `plugins/sabai`. Only `hooks/register.tsx` touches `$`, and any helper taking `$` lives in `register.tsx`.
- Contract types live in `plugins/sabai/types/index.d.ts`, self-contained (no `import`). `StateFamily` and other engine types are in scope inside `declare module 'claude-code'`.
- User-visible text in English, except the Thai spinner words.
- Every text colour must be ≥ 4.5:1 on its card (`tests/themes.test.ts`).
- Values the mod cannot read are hidden, never faked.
- No credentials, no external files, no network.
- No new dependencies.
- Render trees stay under 100,000 characters serialized.
- Svg width/height must be 1–4096 px and its source ≤ 131,072 characters.
- SVG animations:
  - loop in ≤ 1 s, or run once;
  - start from a visible frame;
  - use transforms or opacity only;
  - stop under `prefers-reduced-motion`.
- Transcript `Text`/`Box` colours are theme keys (`success`, `error`, `warning`, `suggestion`, `subtle`).
- A release bumps `version` in both `plugins/sabai/.claude-plugin/plugin.json` and `.claude-plugin/marketplace.json`.
- Commit messages: an imperative subject, then a short bullet list. The trailer is `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Run from the repo root before every commit:
  - `claude plugin validate plugins/sabai`
  - `claude plugin test plugins/sabai`
  - `tsc -p plugins/sabai`

  `claude plugin test` has no per-test filter: it runs all files. Redirect its output to a file and read the tail.

## Review Focus

1. **A guarded call from a subagent.** It must still be refused or asked about, and the count must rise, but it must not write the main turn's receipt. Pinned in Task 6: a subagent Bash call leaves the receipt empty.
2. **`git checkout -- src/a.ts`, `git restore --staged .` and `git clean -n`.** These are everyday commands and must pass. Pinned in Task 3.
3. **Prefs saved by 2.0.0.** They have no `guardRules` and no `chat.receipt`, and must load with the defaults: Guard rules at Block/Ask/Block/Ask and Turn receipt on. Pinned in Task 4.
4. **A turn that only reads files, or a plain answer.** It must show no receipt, not an empty line. Pinned in Task 5 (`receiptText` → `undefined`) and Task 6.
5. **The band with every row on, five agents running and Clawd in the info row.** It must stay under the 100k tree limit. Pinned in Task 9.

```ts
import type { GuardAction, GuardRule } from '../types'

export type Risk = { rule: GuardRule; reason: string }

// Each rule's name and note in Settings, and what it does until the person picks otherwise.
export const GUARD_RULES: Record<GuardRule, { name: string; note: string; action: GuardAction }> = {
  wipe: { name: 'Delete disk or home', note: 'rm -rf aimed at / or ~', action: 'block' },
  force: { name: 'Force-push main', note: 'git push --force to main or master', action: 'ask' },
  env: { name: 'Read .env', note: 'Reading a .env file, with Read or a shell reader', action: 'block' },
  discard: { name: 'Discard uncommitted', note: 'git reset --hard, git clean -f, git checkout/restore .', action: 'ask' },
}

export function riskOf(tool: string, input: { command?: unknown; file_path?: unknown }): Risk | undefined {
  if (tool === 'Read') {
    const path = typeof input.file_path === 'string' ? input.file_path : ''
    return ENV_FILE.test(path) ? { rule: 'env', reason: 'reads a .env file' } : undefined
  }
  if (tool !== 'Bash' || typeof input.command !== 'string') return undefined
  const cmd = withoutData(input.command)
  const rm = /\brm\s+(?:-\w*\s+)*-\w*(?:r\w*f|f\w*r)\w*(?:\s+-\w+)*\s+(\S+)/i.exec(cmd)
  if (rm) {
    const target = rm[1]!.replace(/\/\*?$/, '/')
    if (target === '/' || target === '/*') return { rule: 'wipe', reason: 'deletes the whole disk' }
    if (['~', '~/', '$HOME', '$HOME/', '${HOME}', '${HOME}/'].includes(target)) return { rule: 'wipe', reason: 'deletes your home folder' }
  }
  const force = forcedPush(cmd)
  if (force) return { rule: 'force', reason: `force-pushes to ${force}` }
  if (discards(cmd)) return { rule: 'discard', reason: 'throws away uncommitted work' }
  if (/\b(cat|less|more|head|tail|bat|source|grep|rg)\b/.test(cmd) && ENV_FILE.test(cmd)) return { rule: 'env', reason: 'reads a .env file' }
  return undefined
}

// A git command that throws away work not yet committed, read from each git call's own arguments
// up to the next shell operator: `reset --hard`, `clean` with -f (not a dry run), and `checkout`
// or `restore` of the whole tree (`.`), but not `restore --staged`, which only unstages.
function discards(cmd: string): boolean {
  for (const m of cmd.matchAll(/(?:^|[;&|(]\s*|\n)\s*(?:sudo\s+)?git\s+([^;&|\n]*)/g)) {
    const [sub, ...args] = m[1]!.trim().split(/\s+/)
    if (sub === 'reset' && args.includes('--hard')) return true
    if (sub === 'clean' && args.some(a => /^-[a-z]*f/i.test(a) || a === '--force') && !args.some(a => /^-[a-z]*n/i.test(a) || a === '--dry-run')) return true
    const paths = args.filter(a => !a.startsWith('-'))
    if (sub === 'checkout' && paths.length === 1 && paths[0] === '.') return true
    if (sub === 'restore' && paths.length === 1 && paths[0] === '.' && !(args.includes('--staged') && !args.includes('--worktree'))) return true
  }
  return false
}
```

`echo git reset --hard` must pass. The regex anchors `git` at the start or after a shell operator, so `echo git …` does not match. The test pins it.

export const EMPTY_LOG: TurnLog = { files: {}, commands: 0, failed: 0 }

export type Logged =
  | { tool: 'Edit'; path: string; oldText: string; newText: string }
  | { tool: 'Write'; path: string; content: string }
  | { tool: 'Bash'; command: string; output: string; isError: boolean; at: number }

// One finished call of the main turn folded into its log: a file's added and removed lines, a
// command and whether it failed, and the counts of the last command that ran tests.
export function logged(log: TurnLog, c: Logged): TurnLog {
  if (c.tool === 'Bash') {
    const tests = TEST_COMMAND.test(c.command) ? testResult(c.output) : undefined
    return {
      ...log,
      commands: log.commands + 1,
      failed: log.failed + (c.isError ? 1 : 0),
      ...(tests ? { test: { passed: tests.passed, failed: tests.failed, at: c.at } } : {}),
    }
  }
  const was = log.files[c.path] ?? { added: 0, removed: 0 }
  const change = c.tool === 'Edit' ? asked(c.oldText, c.newText).lines : lines(c.content).map(l => `+${l}`)
  const added = change.filter(l => l.startsWith('+')).length
  const removed = change.filter(l => l.startsWith('-')).length
  return { ...log, files: { ...log.files, [c.path]: { added: was.added + added, removed: was.removed + removed } } }
}

const plural = (n: number, word: string) => `${n} ${word}${n === 1 ? '' : 's'}`

// The turn's receipt, or nothing for a turn that changed, tested and ran nothing.
export function receiptText(log: TurnLog): string | undefined {
  const files = Object.values(log.files)
  const parts: string[] = []
  if (files.length) {
    const sum = (k: 'added' | 'removed') => files.reduce((n, f) => n + f[k], 0)
    parts.push(`✎ ${plural(files.length, 'file')} +${sum('added')} −${sum('removed')}`)
  }
  if (log.test) parts.push(log.test.failed ? `✗ ${log.test.failed} of ${log.test.passed + log.test.failed} failed` : `✓ ${log.test.passed} passed`)
  if (log.commands) parts.push(`› ${plural(log.commands, 'command')}${log.failed ? `, ${log.failed} failed` : ''}`)
  return parts.length ? parts.join(' · ') : undefined
}

export type Mood = 'startled' | 'sad' | 'celebrating' | 'sweating' | 'working' | 'sleeping' | 'idle'
export const STARTLE_MS = 3000
export const CELEBRATE_MS = 4000
export const SLEEP_AFTER_MS = 5 * 60_000
export const SWEAT_AT = 90

// How Clawd feels, the most pressing first: the guard just caught something, the turn's tests
// failed or just passed, the context is nearly full, work is under way, or nothing has happened
// for a while.
export function moodOf(s: { log: TurnLog; contextPercent?: number; now: number; isWorking: boolean; lastTurnAt: number }): Mood {
  const { log, now } = s
  if (log.caught !== undefined && now - log.caught < STARTLE_MS) return 'startled'
  if (log.test && log.test.failed > 0) return 'sad'
  if (log.test && now - log.test.at < CELEBRATE_MS) return 'celebrating'
  if ((s.contextPercent ?? 0) >= SWEAT_AT) return 'sweating'
  if (s.isWorking) return 'working'
  if (s.lastTurnAt > 0 && now - s.lastTurnAt >= SLEEP_AFTER_MS) return 'sleeping'
  return 'idle'
}
