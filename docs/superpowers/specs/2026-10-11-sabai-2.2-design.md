# sabai 2.2.0 — design

Date: 2026-10-11 · Mod: `sabai` · Status: approved in conversation, awaiting spec review

## Goal

Make the band better: it should show what is happening now and where usage is heading, and you should be able to trim it, theme it per OS mode and make it denser. Clawd follows the time of day and a few holidays. The small debts from 2.1 are cleared, and the band is checked on a narrow desktop window and in dark mode.

## Task 1: desktop spike (before anything is built on it)

A throwaway probe, removed afterwards. The owner checks the screen:

1. A band drawing whose bar fill is a class (`.f-probe{fill:#d00}`), overridden in `@media (prefers-color-scheme: dark){.f-probe{fill:#0a0}}`. Does the bar turn green when the OS switches to dark mode, without a reload?
2. A toast on every `session.measure` that carries rate limits, with the time and `percentUsed`. The owner works a few turns and reports how often readings arrive and whether the percent moves between them.

Fallbacks:
- If (1) does not switch, B2 draws the band twice (light and dark skins) in one SVG and hides one with the same media query. The tree size test then covers both.
- If (2) brings readings rarely (less than once per turn) or the percent rarely moves, the forecast's rate is taken from the window's start instead: `percentUsed / elapsed`, where `elapsed = windowLength − resetsIn` (5H = 5 h, 7D = 7 d).

The findings go into CLAUDE.md's engine constraints.

## A1 · Live turn strip

**Where.** A new band row under the info row, only while the main conversation works (`e.props.isWorking`). It leaves when the turn ends.

**What it shows**, left to right:
- Clawd (see "Where Clawd stands");
- the turn's elapsed time (`1m 42s`, the `clock()` format the crew uses);
- the step in progress: an icon and title such as `✎ Editing svg.ts`, `› Run the tests`, `≡ Reading model.ts`, from the tool call in flight. It is empty between calls;
- at the right, the turn's tallies so far from `turnLog`: `✎ 2` (files), `› 5` (commands), `⚗ ✓ 178` or `⚗ ✗ 2` (last test run). A tally shows only when it is above zero.

**State.**
- `turnStartedAt: number` (atom), set by `turn.start`.
- `liveStep: { icon: StepIcon; title: string } | null` (atom). It is set by the main conversation's `tool.call` hooks on Edit, Write, Read and Bash before `next(e)`, and cleared after.
  - The title reuses the running step's title from `stepOf` (`Editing x`, `Reading x`, the command's description or bare command).
  - Subagents' calls do not touch it.

**Clock.** The existing 1 s `$.clock.every` ticks `now` while an agent runs. It also ticks while the main turn works: a module flag set by `turn.start` and cleared by `turn.complete`.

**Setting.** `rows.live` in the Band group (on by default): `Live: what Claude is doing now`.

**Terminal.** One line: `● 1m 42s  ✎ Editing svg.ts   ✎ 2 · › 5 · ✓ 178`.

## Where Clawd stands

There is one Clawd. The first row present takes him:
1. the tasks row;
2. the live strip;
3. the info row.

With `show.clawd` off (B1) there is no Clawd. The tasks row keeps its `●` glyph on the terminal and its bar without him on the desktop.

## A2 · Usage forecast (5H and 7D)

**Samples.**
- Every `session.measure` (and the reading `session.start` takes) appends `{ at, percent }` per limit kind to `usageSamples: Record<'five_hour' | 'seven_day', { resetsAt?: string; points: { at: number; percent: number }[] }>` (atom).
- A new `resetsAt` starts the list over.
- At most 60 points are kept per kind.

**Forecast**, a pure function in `model.ts`:

```ts
forecastOf(points, resetsInMs, now): number | undefined
```

- The rate is a least-squares slope over the points of the last 30 minutes. The fallback rate from the spike applies if Task 1 calls for it.
- It returns the projected percent at reset: `percent + rate × resetsInMs`, capped at 100.
- It returns `undefined` unless all of these hold:
  - at least 2 points, spanning at least 5 minutes;
  - the rate is above 0;
  - the projection is above the current percent by at least 1.

**Drawing (comfortable).**
- The bar gains a ghost run from the current fill to the projected percent: the same colour at opacity .3, or the warn/alert colour if the projection crosses the warning thresholds.
- After the percent, `→ ~74%`, or `→ full` when it reaches 100. The alt says it in words: `5H Limit 38%, ~74% by reset`.

**Drawing (compact).** The ghost run only, no words. The alt still says it.

**Terminal.** After the value: `→ ~74%` dimmed.

## B1 · Choose what the band shows

New prefs, all on by default:

```ts
show: { folder; gitUser; branch; node; context; session; week; clawd }
```

Thresholds:

```ts
warnAt: 60 | 70 | 80   // default 70
alertAt: 85 | 90 | 95  // default 90
```

**Behaviour.**
- `chips()` and `meters()` filter by `show`.
- The guard chip follows the guard alone, as today.
- `level(percent, warnAt, alertAt)` replaces the fixed `WARN_AT`/`ALERT_AT` in the band's colours.
- The limit toast at 90% keeps its fixed 90 (`LIMIT_WARN_AT`): it is an alert, not a colour.

**Settings, Band group.** Under the row toggles:
- **Info chips:** four toggles;
- **Usage cards:** three toggles;
- **Warn at:** three Buttons (60 / 70 / 80), the chosen one primary;
- **Alert at:** three Buttons (85 / 90 / 95);
- **Clawd:** a toggle.

**Loading.** `withDefaults` fills each field, so prefs saved by 2.1 load unchanged in effect.

## B2 · Light/dark skin pair

**Pref.** `darkSkin: string | null` (default `null`, meaning "Same"). Persisted with the rest of `prefs`.

**Look.** `lookOf(skin, darkSkin?)` returns a Look whose skin colours are classes, never inline hex:
- `.f-<role>` for fills;
- roles: `tasks`, `context`, `session`, `week`, `warn`, `alert`, `pill`, `clawd`, plus the existing `.t .m .k .p .c-*`.

**CSS.** The light skin's values come first. The dark skin's go in `@media (prefers-color-scheme: dark){…}`.
- With `darkSkin` null, a named skin emits one set.
- `auto` keeps its built-in light/dark sets, now as classes too.
- This applies to `svg.ts` drawings only (band, agents pane, skin swatches). The transcript's colours are theme keys and are unchanged.

**Refactor.** The places that write a skin colour as `fill="#…"` take a class instead. These are `pixelBar`, the pill, the Clawd tint (sprite colours via a class on the body groups) and the crew/agent marks that use `look.clawd` or `look.bar()`. Native `Text` that takes `look.clawd` or `look.bar()` on the terminal keeps the light skin's hex, since the terminal has no media query.

**Settings, Appearance group.** Under the themes list, **In dark mode** offers `Same` plus the ten skins, each a Button, the chosen one marked.

**Contrast.** `tests/themes.test.ts` already checks each skin. A pair needs no new check, because each skin is checked on its own card.

## B3 · Density

**Pref.** `density: 'comfortable' | 'compact'` (default `comfortable`). Appearance group: two Buttons.

**Compact layout.**
- Gap 8 → 4.
- Usage cards become one line, `CARD_H` 44 → 22: `[mark] LABEL ▓▓▓▓░░ 46%`, the reset countdown `↻1h55m` after the percent when there is room.
- Info chips and the live strip keep their 20 px rows.
- The tasks row stays.
- A test asserts the band is at least 35% shorter than comfortable with the same rows.

The terminal is unaffected.

## C1 · Clawd by time of day and holiday

`accessoryOf(date: Date): Accessory | undefined` is pure, in `model.ts`, using the machine's local time. The first match wins:

| Accessory | When | Drawn as |
|---|---|---|
| `newyear` | 31 Dec – 1 Jan | a striped party hat |
| `xmas` | 24 – 25 Dec | a Santa hat (red, white trim and bobble) |
| `halloween` | 31 Oct | a pumpkin pail held to his right |
| `songkran` | 13 – 15 Apr | a flower-print shirt band across the body and a water pistol held to his right |
| `coffee` | 06:00 – 10:59 | a coffee cup held to his right, with steam |
| `nightcap` | 22:00 – 04:59 | a drooping nightcap |

**Drawing.**
- Accessories are pixel art in `sprites.ts`, drawn by `sprite()` through a new `accessory` option. Hats sit in the existing hat slot (`HAT_H`); held things sit in the existing prop slot.
- Mood marks (`!`, the drop, `z`, confetti) still draw.
- The band's Clawd is the only one that wears them. Crew and agent Clawds keep their type's hat and tool.
- With a hat, the band's row height stays 20 px. The hat may rise above the row, and the band adds top padding only when a hat is on.

**Clock.** The band reads `now` (ticked every 30 s), so an accessory changes within 30 s of the hour.

## D1 · The 2.1 minors

1. **Reads don't count.** A Bash command that only reads (`cat`, `head`, `tail`, `less`, `grep`, `rg`, `ls`, `find`, `wc`, `git status|log|diff|show|branch`) is not counted in the receipt's commands, unless the turn also edited files or ran tests. It still counts as failed if it fails.
2. **`replace_all`.** Edit with `replace_all: true` counts the lines changed times the occurrences when the result's `structuredPatch` is present. Otherwise it counts once and the receipt's file part is unchanged.
3. **`git restore`.** `-S` is treated as `--staged` and `-W` as `--worktree`.
4. **`tool.check` matcher.** The hook takes `{ tool: ['Bash', 'Read'] }`.
5. **`tool.check` `.catch`.** It reuses a pure helper `checkFailClosed(next)`, unit-tested like `failClosed`.
6. **Other plugins' text.** A receipt that falls back to the notice appends to `completed.text` (`text ? text + '\n' + line : line`) instead of replacing it.

## Testing

- **Unit:**
  - `forecastOf`: no points, one point, under 5 min, a flat rate, a rising rate, capped at 100, the 30-minute window;
  - `accessoryOf`: each holiday's edges, coffee 10:59 vs 11:00, nightcap 21:59 vs 22:00 and 04:59 vs 05:00, a holiday at 07:00 beating coffee;
  - `level` with custom thresholds;
  - the read-only command test;
  - `checkFailClosed`.
- **Hooks and UI (terminal and desktop):**
  - the live strip appears while working with the step and tallies, and leaves after;
  - Clawd's row order;
  - the forecast ghost and words when samples allow, and none otherwise;
  - each `show` toggle and threshold changes the band;
  - a dark skin pair emits both sets in the stylesheet;
  - compact is at least 35% shorter;
  - accessories draw for a mocked clock;
  - the tree stays under 100k with every row on, a full crew, a forecast, the live strip and a hat;
  - prefs saved by 2.1 load with the defaults.
- **Contrast:** unchanged rules (≥ 4.5:1 per skin).
- **D1:** one test per minor.
